# Android Automation Tests for media-rs

This directory contains automated test infrastructure for media-rs on Android.

## Structure

- `test_videos/` - Downloaded video test assets
- `test_cases/` - Individual test case implementations
- `automation_core/` - Core automation framework
- `dashboard/` - Test results dashboard
- `logs/` - Test execution logs

## Quick Start

1. **Set up video test assets**: Download sample videos for testing
2. **Run tests**: Execute test suites for thumbnail generation, transcoding, etc.
3. **View dashboard**: Check results in the summary dashboard

## Video Test Assets

The system can download sample videos automatically or you can add your own from the file gallery.
