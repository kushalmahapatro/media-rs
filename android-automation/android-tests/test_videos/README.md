# Test Video Assets

## Downloaded Videos

Place test videos here. The system can download sample videos from these sources:
- Big Buck Bunny (Open movie)
- Sintel (Open movie)
- Tears of Steel (Open movie)
- Sample videos from sample-videos.com

## Adding Videos

1. Download videos to this directory
2. The automation system will detect them automatically
3. Videos are indexed and made available for testing

## Video Formats Supported

The automation system tests with these formats:
- MP4 (H.264, H.265)
- AVI
- MKV
- WebM
- MOV
- 3GP

## Onboarding

When tests start for the first time, an onboarding screen will show:
1. List of downloadable sample videos
2. Option to use existing files/gallery videos
3. Quick download button for all samples
